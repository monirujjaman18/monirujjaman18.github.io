## Free 1-Click Deployment Instructions

### 1. Netlify (Easiest - 30 Seconds, Free)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop) (no account required or login with GitHub).
2. Drag and drop this extracted folder (containing `index.html`, `style.css`, `script.js`, and `images/`).
3. Your site is instantly live with a free SSL HTTPS link!

### 2. Vercel (Fast & Global CDN, Free)
1. Install Vercel CLI via terminal: `npm i -g vercel` or visit [https://vercel.com/new](https://vercel.com/new).
2. In this folder run: `vercel --prod`
3. Site is live instantly with free SSL and edge CDN.

### 3. GitHub Pages (Free forever)
1. Create a new GitHub repository named `monirujjaman18.github.io` (or any repo name).
2. Push or upload these files (`index.html`, `style.css`, `script.js`, `images/`).
3. Go to Repository **Settings** -> **Pages** -> Source: `Deploy from branch (main / root)`.
4. Your site will be live at `https://monirujjaman18.github.io`.

### 4. cPanel / Shared Hosting File Manager
1. Log into your cPanel -> Open **File Manager**.
2. Navigate to `public_html/`.
3. Upload `monirujjaman-static-portfolio.zip` and click **Extract**.
4. Make sure `index.html` is located directly in `public_html/`.
5. Visit your domain - your website is 100% live!
